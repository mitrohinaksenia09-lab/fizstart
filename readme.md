# ФизСтарт — обновление интерфейса

Изменения:

- В разделе **AI-помощник** удалены блоки «Полезные подсказки» и «История запросов».
- AI-раздел стал чище: слева режимы работы, по центру чат.
- На главной странице убран нижний блок с карточками, оставлен только основной hero-блок.
- Сайт остаётся бесплатным и работает локально.

Открой `index.html` в браузере.


## Авторизация и личные результаты

В этой версии добавлен раздел **Вход** и **Кабинет**.

Работает в демо-режиме без сервера:

- регистрация по электронной почте;
- вход по электронной почте;
- вход через кнопки VK и Яндекс ID в локальном демо-режиме;
- сохранение результатов тренировочных вариантов для каждого аккаунта;
- просмотр истории результатов в личном кабинете.

Важно: для настоящего входа через VK и Яндекс ID на опубликованном сайте нужно зарегистрировать приложения в кабинетах VK / Яндекс ID, получить client_id и подключить backend или Supabase Auth. В текущей пробной версии кнопки VK и Яндекс ID работают как локальный вход, чтобы можно было проверить пользовательский сценарий.


## Обновление банка заданий

Добавлен расширенный банк заданий по всем ключевым материалам:

- Механика;
- Молекулярная физика и термодинамика;
- Электродинамика;
- Колебания и волны;
- Оптика;
- Квантовая физика.

Задания добавлены в формате ЕГЭ/ФИПИ: номер, тема, сложность, условие, поле ответа, правильный ответ и решение.
В демо-версии задания хранятся локально в `data.js`.

## Добавлен открытый вариант ФИПИ 2026

В раздел «Тренировочные варианты» добавлен новый вариант: «Открытый вариант ФИПИ 2026» из файла `ФИ.pdf`.

Что включено:
- 26 заданий;
- оригинальные фрагменты заданий с графиками, схемами и таблицами;
- отдельное поле ответа на сайте;
- автопроверка заданий 1–20;
- задания 21–26 отмечаются как развёрнутая часть.
